# WikiText-2 小型过滤与去重案例

本案例位于 coursework/assignment4-data/examples/mini_data_pipeline/，对应第 11 章的数据清洗、过滤与去重内容。样本来自 Salesforce 发布的 WikiText-2 raw 训练集，随案例提供 500 行真实语料；脚本使用 Python 标准库，无需联网或额外依赖即可复现。

## 运行

在本目录执行：

    python pipeline.py --output-dir outputs

脚本生成：

- outputs/cleaned.jsonl：通过清洗的文本行。
- outputs/summary.json：各阶段处理前后的记录数、字符数、UTF-8 字节数与空白分隔 token 数。

也可通过 --input-jsonl 指定其他 JSONL 文件。输入必须逐行包含字符串字段 text。

## 管线与规则

1. **空白规范化**：合并连续空白，移除空行。
2. **精确去重**：对规范化后的全文做大小写不敏感比对，保留首次出现的行。
3. **质量过滤**：移除 Wiki 标题行、少于 5 个空白分隔 token 的短片段，以及字母数字字符少于 40 个的片段。

这是一个可读、可复现的基础案例；阈值是演示用规则，并不代表通用的语料质量标准。summary.json 保留每一步处理前后的数据量，方便检查各项规则的影响。

## 本次运行的数据量对比

使用样本中 500 行运行后的统计如下。字符数和 UTF-8 字节数均按文本内容计算，空白分隔 token 数用于描述样本规模，不等同于特定模型分词器的 token。

| 阶段 | 行数（处理前 → 处理后） | 字符数（处理前 → 处理后） | UTF-8 字节数（处理前 → 处理后） | 移除行数 |
| --- | ---: | ---: | ---: | ---: |
| 空白规范化与空行移除 | 500 → 367 | 153,886 → 152,785 | 154,315 → 153,214 | 133 |
| 大小写不敏感精确去重 | 367 → 363 | 152,785 → 152,729 | 153,214 → 153,158 | 4 |
| 质量过滤 | 363 → 214 | 152,729 → 147,894 | 153,158 → 148,296 | 149 |

最终输出 214 行、28,029 个空白分隔 token，cleaned.jsonl 文件大小为 151,498 字节。完整统计写入 outputs/summary.json。

## 数据来源与授权

- 数据集：[Salesforce/wikitext](https://huggingface.co/datasets/Salesforce/wikitext)，使用 wikitext-2-raw-v1 的 train split。
- 样本由起始行 0、9,000、18,000、27,000 和 36,000 处各连续取 100 行组成，共 500 行；该 split 共 36,718 行。输入样本 SHA-256：4d97d538c24e42ed8a4f91341a1014772d0399665c1ed8d3d793d8dd98f598b3。
- 数据集卡片说明语料来自 Wikipedia 的已验证条目。其页面的 license 元数据列有 CC BY-SA 3.0 和 GFDL，卡片正文则写有 CC BY-SA 4.0。本样例保留来源信息；若另行保存或再分发样本，请依数据集卡片及原文来源要求署名，并核对适用授权。
